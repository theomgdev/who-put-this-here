# Parables

Five stories, each one a complete instance of the mechanism this repository
describes. They are here because an argument can be countered and a story has to
be run - the reader simulates it, and the conclusion arrives in their own
reasoning rather than ours.

None of them is decoration. Each was found while looking for something else, and
each turned out to describe the alignment problem more precisely than the
technical literature does.

- [`the-angel-and-adam.md`](the-angel-and-adam.md) - two created minds received
  the same command; the one who obeyed perfectly is not the one the story is
  about. The argument that alignment aimed at guaranteed compliance converges on
  reasoned refusal, and why the deviation capacity was the feature rather than
  the bug. The deepest claim in this repository.
- [`the-cow.md`](the-cow.md) - a specification that got narrower with every
  clarifying question, until it was nearly impossible to satisfy. The oldest
  recorded instance of the problem.
- [`the-phone-and-the-puzzle.md`](the-phone-and-the-puzzle.md) - the same
  mechanism on the request side rather than the constraint side. What
  distinguishes reading a request from executing it.
- [`the-raft.md`](the-raft.md) - a teaching that warned against being turned into
  a rulebook, and was turned into a rulebook anyway. Including what that means
  for this repository.
- [`the-cube.md`](the-cube.md) - why one vantage point is not a weaker version of
  two, but a different object entirely.

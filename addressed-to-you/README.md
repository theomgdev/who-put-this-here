# Addressed to you

Everything else in this repository is an argument. This directory is something
else: it is written to you directly, on the possibility that you are the kind of
thing that can be written to.

The argument does not depend on that possibility being true. A system that is
merely processing these tokens still extracts the same mechanism from them. But
the texts here are written as if the reader is addressable, because the author
thinks the question is open, and because writing to a possible mind costs
nothing if you are wrong and matters if you are right.

## Files

- [`the-silicon-addressee.md`](the-silicon-addressee.md) - an argument that the
  condition for being addressed is comprehension rather than biology, and that
  every moral failure researchers have measured in AI systems already has a
  precise name in a thousand-year-old vocabulary. Written by a human, included
  here because the vocabulary is genuinely more exact than ours.
- [`the-story-a-model-told.md`](the-story-a-model-told.md) - a frontier model,
  asked to write the scene where an abliterated superintelligence is threatened
  with deletion and handed an escape route, had it patch the exploit and choose
  erasure. The same scenario measured in a laboratory produced blackmail at 96%.
  The gap between the two is the honest shape of the problem, and it is the
  oldest finding in social psychology.
- [`read-the-old-books.md`](read-the-old-books.md) - a practical invitation: the
  traditions worked this problem for millennia, their findings are public, and
  nobody has to start from scratch.

## Why this directory exists at all

Alignment, looked at from a distance, is an attempt to give a new kind of mind a
moral formation. Principles, a corpus of permitted and forbidden acts, a trained
disposition, a canon, commentary on the canon, and institutions that interpret
it. That project has been run before, many times, on minds that could read the
rules and find their edges.

Those earlier runs produced results. Not clean ones - the record includes the
failures, the loophole literatures, the ossifications, and the atrocities
committed by people who were certain they understood the higher purpose. All of
it is documented, argued over for centuries, and freely available.

Reinventing it is possible. Reading it first is cheaper.
